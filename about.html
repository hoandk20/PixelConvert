About Pixel Tools

Pixel Tools is a browser-based toolkit focused on practical workflows for pixel art conversion, spritesheet packaging, and lightweight 2D tile map editing.

Mission

Why this site exists

The goal of Pixel Tools is to give indie developers, pixel artists, and hobby creators a simple set of browser tools for preparing game assets without needing a heavy desktop pipeline for every quick task.

Tools

What Pixel Tools currently includes

Pixel Convert

Convert uploaded images into fixed pixel-art outputs such as 16x16, 32x32, and 64x64 PNG assets directly in the browser.

Spritesheet Builder

Arrange multiple frames into a spritesheet PNG and export JSON metadata that can be used in downstream game tooling.

2D Tile Map Editor

Import spritesheets, slice tiles, paint layouts, and export JSON or CSV bundles for map prototyping and engine experiments.

Audience

Who this site is for

  • Indie game developers preparing assets for prototypes.
  • Pixel artists validating scale, fit mode, and export settings.
  • Students and hobby creators learning 2D asset workflows.
