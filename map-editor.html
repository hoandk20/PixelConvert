Overview

What this 2D tile map editor is built for

Pixel Tools Map Editor is designed for indie developers, pixel artists, and level designers who need a lightweight browser workflow for assembling game maps. This page now explains the editing workflow, supported exports, and common use cases so visitors can understand the product before opening or saving a project.

Workflow

Typical map-building flow

1. Import tilesets

Load one or more PNG spritesheets, then define spacing and margin so the editor can slice the sheet into individual paintable tiles.

2. Organize layouts

Create multiple layouts for floor, props, collision, or decorative details, then drag to reorder them in the draw stack.

3. Export project data

Save editor JSON for later edits, or export engine bundles and CSV data when you need a handoff for development or testing.

Use Cases

When this editor is useful

Rapid level blocking

Sketch a room layout, dungeon, or platforming zone before moving into a larger engine or desktop map pipeline.

Asset validation

Test whether a tileset reads clearly at a given tile size and check seams, spacing, and repeated patterns directly in the browser.

Collaboration handoff

Share exported JSON and spritesheet bundles with programmers or teammates who need structured map data instead of screenshots.

Export Guide

Formats and project data explained

Project JSON

Keeps editor-specific state such as layouts, tileset references, map size, and local progress so you can reopen the same project in the browser later.

Engine ZIP

Packages tilemap JSON with the current spritesheet PNG for faster handoff into engine experiments and early gameplay tests.

CSV Bundle

Exports the active layer in a simple grid-friendly format that is useful for custom importers or spreadsheet-style inspection.

FAQ

Questions about the map editor

Do I need a full spritesheet before I can start?

No. You can begin with a single small sheet or a rough prototype PNG, then replace it later as your art pipeline matures.

What is the difference between Project JSON and Engine ZIP?

Project JSON is for reopening and editing inside Pixel Tools. The Engine ZIP is a delivery format meant for use outside the editor.

Can I build collision or logic layers?

Yes. Create multiple layouts and use the block marker to separate structural or collision-oriented data from visual decoration.

Is this page intended as a production editor or a fast prototype tool?

It is primarily a fast browser-based prototyping tool for pixel map layout, tileset testing, and lightweight export workflows.
